# 滑雪大冒险 / Ski Safari

Vite + CoffeeScript + SCSS 打造的下坡滑雪冒险游戏。

## 快速开始

```bash
npm install
npm run dev
```

浏览器打开终端提示的本地地址即可游玩。

## 操作

| 操作 | 电脑 | 手机 |
|------|------|------|
| 转向 | ← → / A D | 左右按钮或左右滑动 |
| 跳跃 | 空格 / ↑ | ↑ 按钮或上滑 |
| 下蹲加速 | Z / ↓ | ↓ 按钮或下滑 |
| 空中特技 | X | ★ 按钮 |
| 暂停 | P / Esc | 右上角暂停 |

## 内容

- **6 个关卡**：粉雪、冰道、密林、高山、极夜、火山
- **4 种难度**：轻松 / 标准 / 极限 / 雪崩
- **收集**：金币、宝石、护盾、磁铁、加速、生命
- **障碍与敌人**：岩石、树木、雪人、冰块、雪怪、企鹅、无人机
- **连击特技**：空中翻转打连击拿高分
- 进度自动保存在本地（通关解锁下一关）

## 构建

```bash
npm run build
npm run preview
```
