# blender 插件 sbweight

为骨骼刷权重时，传统的普通刷权重笔刷并没有那么的好用，尤其模型有多个面时、细节较小时比如手指，权重的投射功能也没那么方便，本插件采用“包围盒”思维，通过“代理骨骼”实现快速权重，尽可能少的减少刷权重的操作。

## 亮点

### 骨骼代理

在权重绘制模式或姿态模式下，选中一根骨骼，点击插件里的“根据所选骨骼创建包围盒”按钮即可创建一个包围盒空物体，该空物体会自动跟随骨骼的姿态变化自身大小、位置、缩放，属于每段骨骼的子级。

在物体模式下选中该空物体，就可以在插件面板查看到此空物体所代理的骨骼是哪一根，调节大小范围即可刷新对应骨骼的权重。

支持批量创建，比如您可以选中多根骨骼，点击插件里的“根据选中骨骼创建包围盒”按钮，即可批量创建多个包围盒空物体，每个包围盒都属于对应单根骨骼的子级。

默认是立方体包围盒，您可以在“选择包围盒形状”的下拉菜单里选择其它形状的包围盒，只支持立方体和球形包围盒，创建好后支持直接切换。

一个骨骼支持创建多个包围盒。

### 包围盒动态权重

使用空物体包围盒一键权重，期间可通过调整包围盒的大小、位置等参数动态刷新权重。

### 自动规格化

默认开启自动规格化，降低多根骨骼操控同一个物体时可能会出现的权重错误。

### 清理

刷好权重并检查没什么问题的时候，您可以点击插件上的 

姿态模式下：
    - “移除所选骨骼的包围盒”
    - “移除本骨架上的所有包围盒”
物体模式下：
    - “移除选中的包围盒”
    - “移除场景中所有包围盒”


来清理包围盒，优化性能。

### 范围封闭

本插件在刷权重时，遵循“权重只分配给处于包围盒内部的顶点”的原则。

默认情况下，刷权重的规则是越处于包围盒中心的顶点，权重就越大，距离包围盒边界越近的顶点权重越低，包围盒外部的顶点权重永远为0。

选中某个包围盒，就可以在插件面板里的 “权重规划” 选项卡里调节自动分配权重时的权重分布，每个包围盒的权重规划各自独立。

支持以下几个数值：

    - 中心，默认值为1，
    - 顶点1，默认值为0.2，
    - 顶点2，默认值为0.2，
    - 顶点3，默认值为0.2，
    - 顶点4，默认值为0.2，
    - 顶点5，默认值为0.2，
    - 顶点6，默认值为0.2，
    - 顶点7，默认值为0.2，
    - 顶点8，默认值为0.2

以上默认值下，包围盒里的顶点越是处于包围盒中心，权重就越趋近或等于1；
越是趋近包围盒边界，权重就越趋近或等于0.2。

各个顶点所代表的位置分别是立方体包围盒的：
1左上后、2右上后、3左上前、4右上前、
5左下后、6右下后、7左下前、8右下前

如果选中的是球形包围盒，那么只支持以下数值：

    - 中心，默认值为1，
    - 边界，默认值为0.2
