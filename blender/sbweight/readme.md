# SBWeight — 骨骼包围盒权重插件

用「包围盒代理」快速给骨骼刷权重。适合多面片、手指等细节部位，减少传统权重笔刷和权重投射的反复操作。

侧栏入口：**3D 视图 → N 面板 → SBWeight**

## 兼容版本

| 范围 | 说明 |
|------|------|
| **推荐 / 已验证** | Blender **5.2.x** |
| **建议最低** | Blender **4.2+** |
| **预期可用** | Blender **4.2 → 5.x** |
| **未充分测试** | 3.6 / 4.0–4.1（多数功能理论可用，不保证） |

## 安装

1. 将整个 `sbweight` 文件夹复制到 Blender 的插件目录，例如：
   - Windows：`%APPDATA%\Blender Foundation\Blender\<版本>\scripts\addons\`
2. 打开 **编辑 → 偏好设置 → 插件**
3. 搜索并启用 **SBWeight - Bone Bounding Box Weights**
4. 在 3D 视图按 `N`，找到 **SBWeight** 面板

开发调试也可把 `sbweight` 的上一级目录加入 `sys.path` 后 `import sbweight; sbweight.register()`。

## 核心思路

1. 在姿态 / 权重绘制模式下选中骨骼，为每根骨骼生成一个（或多个）包围盒空物体  
2. 空物体作为骨骼子级，跟随姿态的位置、旋转、缩放  
3. **只给落在包围盒内部的顶点分配权重**；盒外恒为 0  
4. 调整盒子大小、位置、权重规划时，可动态刷新权重  
5. 刷完后删除包围盒即可；**删除包围盒不会清空已刷好的权重**

## 功能亮点

### 骨骼代理包围盒

- 姿态模式或权重绘制模式下，选中一根或多根骨骼 → **根据所选骨骼创建包围盒**
- 支持批量创建；一根骨骼可挂多个包围盒（同骨骼取较大权重）
- 形状：**立方体** / **球形**，创建前可选，创建后也可切换
- 物体模式选中空物体，面板会显示其代理的骨架与骨骼名

### 动态权重 + 实时预览

- 开启 **变换时动态刷新权重** 后，移动 / 缩放包围盒会即时改权重
- 开启 **实时权重预览**（默认开）后，物体模式下即可在网格上看到蓝→红热力图，无需切到权重绘制模式
- 也可手动点 **刷新权重**

### 自动规格化

默认开启。当同一顶点被多根骨骼影响且权重总和超过 1 时，自动按比例下调，避免溢出；不会把单骨骼的衰减强行拉成 1。

### 范围封闭与权重规划

盒内：越靠近中心权重越高，越靠近边界越低；盒外永远为 0。

每个包围盒的规划独立。选中包围盒后可在面板调节：

**立方体**

| 参数 | 默认 |
|------|------|
| 中心 | 1.0 |
| 顶点 1～8 | 0.8 |

顶点方位（立方体局部）：

1 左上后 · 2 右上后 · 3 左上前 · 4 右上前  
5 左下后 · 6 右下后 · 7 左下前 · 8 右下前

**球形**

| 参数 | 默认 |
|------|------|
| 中心 | 1.0 |
| 边界 | 0.2 |

### 权重增减

选中包围盒后，用 **权重增减** 浮点值对盒内顶点整体加减（如 `0.1` / `-0.5`）。  
只影响当前包围盒；各盒子互不干扰。  
**应用权重增减** 会把当前增减烘焙进中心 / 顶点（或边界）参数，并把增减归零。

### 清理（只删空物体，不改权重）

| 模式 | 操作 |
|------|------|
| 姿态 / 权重绘制 | 移除所选骨骼的包围盒 · 移除本骨架上的所有包围盒 |
| 物体模式等 | 移除选中的包围盒 · 移除场景中所有包围盒 |

### 多语言

面板支持 **中文 / English / 日本語 / 한국어** 切换。

## 推荐工作流

1. 准备好骨架，网格带 Armature 修改器（或已父子到骨架）  
2. 进入 **姿态模式** 或 **权重绘制模式**，选中要刷的骨骼  
3. 在 SBWeight 面板选择包围盒形状，点击 **根据所选骨骼创建包围盒**  
4. 切到 **物体模式**，选中包围盒空物体  
5. 确认已开启 **实时权重预览** 与 **变换时动态刷新权重**  
6. 调 Size / Scale / 位置，以及权重规划、权重增减，直到热力图满意  
7. 需要时点 **应用权重增减**  
8. 检查无误后，用清理按钮删除包围盒（权重保留）

## 面板说明

- **语言**：界面语言  
- **包围盒形状**：新创建时使用的形状  
- **自动规格化**：多骨骼权重溢出时下调  
- **变换时动态刷新权重**：拖动包围盒时自动重算  
- **实时权重预览**：物体模式用顶点色显示当前代理骨骼权重  
- **根据所选骨骼创建包围盒**：仅在姿态 / 权重绘制且已选骨骼时可用  

选中代理空物体后还会显示：代理骨架 / 骨骼、形状切换、尺寸、刷新、权重规划、权重增减与清理区。

## 注意事项

- 创建按钮在物体模式（未处于姿态 / 权重绘制）下会呈灰色，属正常  
- 权重写在与骨骼同名的顶点组上；请保证网格由对应骨架变形  
- 实时预览会把相关 3D 视图切到「实体 + 顶点色」着色；关闭预览可恢复之前的着色设置  
- 预览颜色属性名：`SBW_WeightPreview`（一般无需手动改）  
- 包围盒默认尺寸按骨长估算，复杂网格请再手动放大 / 缩小以包住目标部位
