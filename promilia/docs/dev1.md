我想开发以下功能，使用python实现。

阶段一：

1. 检查电脑上是否安装了任何类型的安卓模拟器，比如雷电模拟器、MuMu模拟器（中国市面上的那些模拟器），并列出清单。
2. 如果没有安装任何类型的安卓模拟器，提示用户安装一个
3. 完成上述步骤后，下面的内容以雷电模拟器为例进行说明
3.1 检查是否启动了模拟器，如果没有，提示是否启动模拟器，是(启动)，否(退出程序)
3.2 选择是的时候，监听启动过程，并尝试与模拟器通信（adb等方式），检测是否已进入模拟器桌面
3.3 获取1张模拟器截图并保存到本地，用来测试是否正常进入界面
3.4 获取已安装的应用列表，列出清单(名称、包名)
3.5 获取模拟器的设置的分辨率（比如1280*720这种信息）、设置的机型、安卓版本等信息并列出
3.6 获取并列出用户的PC电脑内存信息、列出网络是否已连接
3.7 一切正常后，尝试启动包名为"com.oddyarts.AurumBladeEXNative(黄金之剑)"的应用（可配置，配置支持使用应用名称或者包名）
3.8 检测是否已启动
4. 以下是开发规范
4.1 性能优先，在此基础上保持交互友好，提示友好
4.2 涉及到缓存/创建文件等操作，优先缓存到与软件/脚本所在目录相同的目录下
4.3 启用日志功能
4.4 配置文件使用yaml格式
