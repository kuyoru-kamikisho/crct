# 黄金矿工 · Gold Miner

网页版黄金矿工小游戏。纯前端，无需构建，用浏览器打开即可玩。

## 运行

直接双击打开 `index.html`，或在目录下起一个本地服务：

```bash
npx serve .
```

## 操作

| 操作 | 方式 |
|------|------|
| 发射钩爪 | 空格 / 点击画面 |
| 使用炸药 | `D` / `X` / 点击炸药栏 |
| 暂停 | `Esc` / `P` |

## 玩法

- 每关有目标分数与倒计时，达标后进入商店购买强化
- 金块值钱，石头笨重；钻石轻且昂贵；神秘袋价值随机
- 商店可买力量药水、炸药、幸运草、磁铁钩等
- 共 8 关，难度与目标逐步提升
