# Lumen Break · 流光打砖块

Vite + React + TypeScript 模块化实现的 Arkanoid（快打砖块）小游戏。

## 启动

```bash
npm install
npm run dev
```

## 操作

- 鼠标 / 触控移动挡板
- 点击或空格发射光球
- `Esc` 暂停
- 获得「光刃」道具后按 `F` 发射激光

## 内容

- 4 种难度：闲适潮汐 / 经典流光 / 深渊脉冲 / 混沌棱镜
- 8 个主题关卡，含装甲、爆炸、幽灵、水晶、传送等特殊砖
- 创意道具：裂球、光刃、黏附、延展/收缩、时缓、护幕、磁引
- 连击加分、粒子反馈、屏幕震动与合成音效
