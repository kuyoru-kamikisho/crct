# 项目概述

本项目旨在开发一个用图形、表格、公式、文字等形式让人更加容易学习TA（技术美术）相关知识的网站。

技术美术理论包含大量的数学知识、图形学知识、计算机知识等，在学习的时候只看理论很难理解对应的知识到底讲的什么，有良好的图形演示的话相信学习也会更加容易，这就是本项目的目的，哪怕是1+1，也会有对应的图形演示来介绍为什么1+1等于2，致力于“就算从未学过相关内容也能看懂”。

## 开发准则

1. 涉及到数学公式的，必须在下面追加公式中各个字母字符的含义
2. **任何**知识点，都应该开发对应的“演示器模块”，演示器包含“参数调节面板”、“图形演示区”、“结果显示区”等部分
   以“点乘运算”为例，开发一个“点乘运算演示器”，
   用户可以在“参数调节面板”中调整向量A和向量B的坐标或角度，
   然后在“图形演示区”中展示坐标轴、向量A和向量B点位置的图形，
   同时在“结果显示区”中显示点乘运算的详细过程以及结果。
   “图形演示区”可以采用canvas等方式实现，支持3d坐标轴。
   如果使用到了3d坐标轴，那么“图形演示区”应当可以右键旋转空间视图(摄像机机位)；
   如果使用到了2d坐标轴，那么“图形演示区”应当可以通过鼠标拖动坐标点快速设置点的坐标。
   “演示器模块”根据知识不同，其功能也可能会产生很大的不同，开发时要考虑好可扩展性，不行可以每个知识点开发一个独立的演示器，演示器要尽可能地有好的交互体验。
3. 涉及到代码、公式等内容的最好有代码高亮等显示效果
4. 使用vite进行构建，其他技术栈、npm依赖等可以任意取舍使用，以实现需求为优先
5. 支持站内全局搜索功能，可以通过搜索快速打开对应的知识页面
6. 如果有的知识来自互联网视频比如youtube、bilibili或者博客等，那么要给出对应的跳转链接

基于以上，要求交互体验尽可能地好，界面尽可能地美观，按钮等元素的圆角不宜过大使用2px，页面主体使用暗色调。
项目中可以使用mdi图标库增加美观度，创建项目时无需追加ts、eslint等辅助工具。

## 开发内容

假设用户是一个有3年web前端开发经验的人，打算零基础转TA（技术美术）相关工作，此网站应该有尽可能多的相关知识，包括但不限于：

1. 按学习路线顺序排序的知识点
2. 工作时容易遇到的问题及解决方案
3. 面试时的高频问题以及答案
4. TA工具相关下载链接
5. 作品集社区相关链接
6. 其它内容

内容要尽可能的优质以便于能让用户确确实实的好找工作，需要实践的知识点要有按步教学以便于用户能够通过实践来理解。
