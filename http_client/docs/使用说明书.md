# HTTP Client 使用说明书

类似 JetBrains HTTP Client 的桌面接口测试工具。用纯文本编写请求，支持语法高亮、环境变量、一键运行、curl 导入、流式响应、文件下载与 WebSocket。

## 1. 运行与构建

### 开发运行

```bash
cd http_client
flutter pub get
flutter run -d windows
```

### 发布构建

```bash
flutter build windows
```

构建产物位于：

`build/windows/x64/runner/Release/http_client.exe`

## 2. 数据目录（不占用 AppData）

软件会在 **可执行文件同级目录** 下创建 `http_client_data/`：

| 文件/目录 | 说明 |
|-----------|------|
| `settings.json` | 主题、选中环境、分割比例等 |
| `http-client.env.json` | 环境变量 |
| `history.json` | 历史记录（最多 200 条） |
| `draft.http` | 自动草稿 |
| `downloads/` | 文件下载默认目录 |

开发模式下，该目录会出现在 Flutter 引擎可执行文件旁；发布后则与 `http_client.exe` 同级。

## 3. 界面概览

- **顶部工具栏**：新建 / 打开 / 保存、历史、导入 curl、格式化、运行当前 / 运行全部、环境选择、模板、主题切换
- **中间编辑器**：行号、左侧绿色播放按钮、语法高亮
- **下方响应面板**：Body / Headers / WebSocket / Results 四个 Tab
- **底部状态栏**：当前状态、请求数量、数据目录提示

界面统一使用 `border-radius: 0` 的直角风格，提供黑灰 / 明亮两套主题。

## 4. 请求书写格式

多个请求用 `###` 分隔：

```http
### 获取用户
GET {{host}}/get
Accept: application/json
Authorization: Bearer {{token}}

### 创建用户
POST {{host}}/post
Content-Type: application/json

{
  "username": "{{username}}",
  "id": "{{$uuid}}"
}
```

### 规则摘要

1. **请求行**：`METHOD URL`，例如 `GET https://example.com`
2. **请求头**：紧随请求行，格式 `Key: Value`
3. **空行**：请求头与请求体之间必须有空行
4. **请求体**：空行之后的内容
5. **注释**：`#` 或 `//` 开头
6. **注解**：`# @name xxx`、`# @download`、`# @stream`、`# @timeout 60000`、`# @insecure`
7. **查询参数可换行**：
   ```http
   GET {{host}}/search
       ?q=flutter
       &page=1
   ```
8. **文件作为请求体**：`< ./payload.json`
9. **下载输出**：`>> filename.bin` 或注解 `# @download`

## 5. 支持的请求类型

| 类型 | 写法示例 | 说明 |
|------|----------|------|
| 普通 HTTP | `GET/POST/PUT/PATCH/DELETE/HEAD/OPTIONS...` | 常规 REST |
| GraphQL | `GRAPHQL https://api/...` | 自动按 POST + JSON 发送 |
| SSE / 流式 | `SSE url` 或 `# @stream` + `Accept: text/event-stream` | 持续追加响应文本 |
| 文件下载 | `# @download` 或 `>> path` | 保存到 `http_client_data/downloads/` |
| WebSocket | `WEBSOCKET wss://...` 或 `WS` / `WSS` | 连接后可在下方 WebSocket Tab 发送文本 |

### WebSocket

```http
### Echo
WEBSOCKET wss://echo.websocket.events

hello
```

- 请求体中的文本会在连接成功后自动发送一次
- 之后可在响应面板 **WebSocket** Tab 的输入框继续发送

## 6. 环境变量

工具栏选择 `Run with:` 环境，或点击调谐图标编辑。

在文本中使用双花括号：

```http
GET {{host}}/users/{{userId}}
```

### 内置变量

| 变量 | 含义 |
|------|------|
| `{{$uuid}}` / `{{$guid}}` | 随机 UUID |
| `{{$timestamp}}` | Unix 秒级时间戳 |
| `{{$isoTimestamp}}` | UTC ISO-8601 |
| `{{$randomInt}}` | 0–999 随机整数 |
| `{{$randomInt8}}` | 更大范围随机整数 |

环境文件示例（`http_client_data/http-client.env.json`）：

```json
{
  "dev": {
    "host": "https://httpbin.org",
    "token": "dev-token",
    "username": "demo"
  },
  "prod": {
    "host": "https://api.example.com",
    "token": "prod-token"
  }
}
```

## 7. 运行请求

- 点击请求行左侧 **绿色播放按钮**
- `Ctrl+Enter`：运行光标所在请求
- `Ctrl+Shift+Enter`：运行文件内全部请求
- 工具栏播放 / 播放列表图标：同上

执行结果出现在下方 Tab；行号旁会显示成功 / 失败图标。

## 8. 导入 curl

点击工具栏「导入」图标，粘贴 bash 或 Windows cmd 的 curl：

```bash
curl -X POST 'https://httpbin.org/post' \
  -H 'Content-Type: application/json' \
  -d '{"hello":"world"}'
```

或：

```bat
curl.exe -X GET "https://example.com" ^
  -H "Accept: application/json"
```

软件会转换为 `.http` 文本并追加到编辑器。

支持常见参数：`-X/-H/-d/--data-raw/-F/-u/-A/-b/-I/-G/-o/-k/-L/--url` 等。

## 13. 常见问题

**Q: 为什么找不到草稿 / 环境文件？**  
A: 请到 exe 同级的 `http_client_data/` 查找，不要去 `%AppData%`。

**Q: WebSocket 发送框是灰的？**  
A: 需要先成功运行 `WEBSOCKET` 请求且连接保持未关闭。

**Q: 下载文件在哪？**  
A: 默认 `http_client_data/downloads/`；若写了绝对路径的 `>>`，则按该路径保存。

**Q: 证书错误的自签名站点？**  
A: 可在请求上加 `# @insecure`（当前版本会记录该注解；桌面 http 客户端对证书策略受系统与 Dart IO 限制，生产环境请优先修复证书）。
