# 项目目录及文件索引

使用AI开发时只在需要时读取相关文件，不必全部读取。

## 文件

- [instructions.md](./instructions.md) 项目说明文档，简单介绍项目的用途
- [frontendSpec.md](./frontendSpec.md) 前端开发规范，前端开发时应遵循此规范
- [backendSpec.md](./backendSpec.md) 后端开发规范，后端开发时应遵循此规范
- [databaseSpec.md](./databaseSpec.md) 数据库开发规范，数据库开发时应遵循此规范

## 目录

- [demand_docs](../demand_docs) 需求文档目录，使用AI开发时的原始需求都会写在这里，无论是项目初始化还是页面需求，每一个页面级应用都有相对应的目录
- [fronted](../../source/fronted) 前端工程目录
- [backend](../../source/backend) 后端服务工程目录
- [database](../../source/database) 数据库工程目录
