# 前端开发规范

- 最优先考虑界面中元素的样式是否好看、交互是否合理、整体是否美观，其次才考虑功能的可用性
- 页面的颜色样式、布局等应当丰富，符合潮流酷炫、时尚游戏风格的审美，该前端非商品购物等产品，而是面向游戏玩家，因此交互图标之类的内容必须趋近“游戏UI”
- 颜色、宽高、布局排版、页面切换、按钮点击、元素的出现和隐藏等，涉及到样式变化的，应当具有动画过度效果
- 如果使用了路由技术，页面的路由必须与页面文件的所在路径和文件名强相关，这样既可以根据路由得到文件位置，也可以根据文件位置知道路由
- 页面的排版布局等，应当尽可能地适配各种大小各种类型的屏幕，无论是手机、电脑、平板电脑等，当屏幕尺寸发生变化时，页面的布局不应该混乱而是自由适应
- 单个页面文件、组件文件、工具方法等代码文件的代码量不应超过1500行
- 变量、文件等的命名应当易于理解，易于维护
- 常用的样式表应当独立出来以便于在其他文件引用，比如全局样式、全局过渡动画等
