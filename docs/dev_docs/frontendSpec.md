## 前端开发规范

- 优先级要求：优先保障界面视觉美观度、交互合理性及整体协调性，在此基础上确保功能可用、稳定，兼顾体验与实用性。
- 视觉风格要求：页面配色、布局设计需丰富多元，贴合潮流酷炫的时尚游戏审美。因产品面向游戏玩家，非商品购物类产品，所有交互图标、界面元素需严格贴合“游戏UI”风格，凸显游戏氛围感。
- 动画效果要求：所有涉及样式变化的场景（含颜色切换、宽高调整、布局排版变动、页面切换、按钮点击反馈、元素显隐等），均需添加流畅的动画过渡效果，提升交互质感与游戏沉浸感。
- 路由规范：若使用路由技术，页面路由需与文件所在路径、文件名强关联，实现“路由可定位文件位置、文件位置可对应路由”，提升项目可维护性与查找效率。
- 适配要求：页面排版与布局需具备强适配性，全面兼容手机、电脑、平板电脑等各类设备及不同尺寸屏幕，屏幕尺寸变化时，页面布局需自动适配、不混乱、不错位，保障多设备一致体验。
- 代码量限制：单个页面文件、组件文件、工具方法等各类代码文件，代码量不得超过1500行，避免文件冗余，便于后期维护与迭代。
- 命名规范：变量、文件、组件等命名需简洁易懂、语义清晰，贴合业务场景，便于团队协作开发与后期维护，避免模糊化、无意义命名。
- 样式管理：常用样式表（如全局样式、全局过渡动画、通用组件样式等）需独立拆分，形成可复用模块，便于在各类文件中统一引用，提升开发效率与样式一致性。
