## 需求列表

- 可路由
- 展示id
- 可查看修改用户名（username），输入框，失去焦点时校验用户名的可用性
- 可注销用户（deleted_at），注销前需要弹出确认框
- 可查看并重新设置生日（birthday）
- 可查看并重新编辑简介（bio）长文本框，注意限制字数（含中文）
- 性别（gender）radio单选
- 职位（position）输入框,注意限制字数（含中文）
- 取消、保存按钮，取消：重置表单，取消前弹出“取消后您所做的更改都会丢失，是否继续”确认框，保存：向后端提交新数据，保存前弹出确认框
- 接口调用成功与否需要有提示
