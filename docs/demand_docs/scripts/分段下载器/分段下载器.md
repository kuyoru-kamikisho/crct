分段下载器需求说明书：

### 需求清单：

- 这是一个命令行形式的网络资源下载器
- 尽可能地实现与“Internet Download Manager”同样快的下载速度
- 使用cmd语言实现以便于在各大平台使用
- 分段下载以便于最大限度地利用网络，下载完成后不要忘记合并

### 用法

- 启动cmd程序后，等待用户输入资源的下载链接，按下回车后开始在当前目录进行下载，cmd在哪个目录被运行，就默认下载到哪个目录

### 注意点

- 合并后的资源不应该损坏，比如下载后来安装包等文件后应该可以正常运行不会损坏。
- 实现的脚本放到 “D:\code\crct\docs\demand_docs\scripts\分段下载器” 目录下
